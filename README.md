# Personal Professional Homepage

This is a self-contained static personal homepage.

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `personal-homepage`.
2. Upload `index.html`.
3. In GitHub: Settings → Pages.
4. Select the main branch and root folder.
5. GitHub will provide the Pages URL.
6. For a custom domain, add your domain under Pages → Custom domain and follow your domain registrar's DNS instructions.

## Personalize before publishing
Replace:
- LinkedIn placeholder
- ResearchGate placeholder
- ORCID / Google Scholar placeholder
- Any wording you want to make more specific
- Publication links/DOIs when available

The page intentionally avoids confidential employer/project information.
